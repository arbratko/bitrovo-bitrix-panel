# Как помочь этому репозиторию

Это публичный репозиторий **документации** продукта Bitrovo: Bitrix Panel.
Исходный код панели сюда не принимается и не публикуется.

## Что можно присылать

- опечатки и неточности в документации;
- улучшения инструкций по установке, ОС и диагностике;
- описания проблем, которые встречаются при установке с CDN.

## Что не нужно присылать

- исходный код, патчи к панели, скрипты установщика;
- пароли, токены, содержимое `/etc/bitrovo-panel`, закрытые ключи;
- отчёты об уязвимостях в открытых issues — только по [SECURITY.md](SECURITY.md).

## Вопросы по продукту

Обращения по работе уже установленной панели удобнее отправлять через раздел
«Поддержка» внутри панели или через [bitrovo.ru](https://bitrovo.ru).
