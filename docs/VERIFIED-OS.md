# Где панель можно устанавливать: проверенные ОС

Здесь перечислены системы, на которых работа системы проверена и
гарантирована. Последняя полная проверка: версия 1.0.31, 20 июля 2026.

## Что именно проверяется на каждой ОС

На каждой ОС из таблицы прогоняется единый сквозной сценарий:

1. установка панели одной командой с CDN (`--full`: nginx, HTTPS,
   MariaDB, PHP-FPM);
2. вход в панель через HTTPS (как реальный клиент, через nginx);
3. установка Redis через панель;
4. установка Push / RTC-сервера через панель (обе службы должны подняться);
5. установка дополнительной версии PHP (8.3) через панель;
6. проверка, что все службы в состоянии `active`.

## Гарантированно поддерживается (проверено)

| Операционная система | Панель | Redis | Push / RTC | Версии PHP |
| --- | --- | --- | --- | --- |
| Ubuntu 20.04 LTS | да | да | да | нет¹ |
| Ubuntu 22.04 LTS | да | да | да | да (PPA ondrej/php) |
| Ubuntu 24.04 LTS | да | да | да | да (PPA ondrej/php) |
| Ubuntu 26.04 LTS | да | да | да | позже² |
| Debian 11 | да | да | да | да (Sury) |
| Debian 12 | да | да | да | да (Sury) |
| Debian 13 | да | да | да | да (Sury) |
| BitrixVM 9 (CentOS Stream 9) | да³ | да | да | да (remi) |
| CentOS Stream 9 | да | да | да | да (remi) |
| CentOS Stream 10 | да | да⁴ | да | да (remi) |
| AlmaLinux 9 | да | да | да | да (remi) |
| Rocky Linux 9 | да | да | да | да (remi) |

¹ Ubuntu 20.04 достигла конца стандартной поддержки, и PPA ondrej/php
удалил сборки PHP для неё. Панель честно сообщает об этом и рекомендует
обновить ОС. Всё остальное работает полностью.

² Для новых выпусков Ubuntu сборки PHP в PPA появляются с задержкой после
выхода ОС. Панель сообщает об этом; версии станут доступны автоматически.

³ BitrixVM проверялась на реальной VPS: install → update → rollback →
uninstall рядом с работающим Битриксом.

⁴ В CentOS Stream 10 / RHEL 10 пакет redis заменён на Valkey (официальный
совместимый форк). Панель автоматически устанавливает его; Push-сервер и
сайты работают без изменений.

Требования одинаковы для всех: `x86_64`, systemd, root-доступ,
публичный IPv4, доступный порт 80 (для сертификата Let's Encrypt).

## Работает и на «занятых» серверах

Панель не требует чистого сервера. Проверено на сервере с BitrixVM
(nginx Битрикса на портах 80/443, Apache, MySQL, PostgreSQL, firewalld):

- панель автоматически уходит на отдельный HTTPS-порт (9443), если 443 занят;
- существующие сайты, конфигурации и пакеты не изменяются;
- при любой ошибке установщик откатывает свои изменения.

## Адаптер готов, но полный цикл ещё не прогонялся

- AlmaLinux 10, Rocky Linux 10;
- RHEL 9 и 10.

Эти системы используют те же проверенные адаптеры (apt / dnf), установка
скорее всего пройдёт, но официальная гарантия появится после полного цикла
тестов на каждой.

## Не поддерживается (установщик откажется до любых изменений)

- Ubuntu 18.04 и старше (устаревшие glibc и OpenSSL);
- CentOS Linux 7/8 и старые BitrixVM 7.x (системы сняты с поддержки);
- Alpine, Arch, openSUSE, системы без systemd;
- архитектуры, кроме `x86_64` (arm64 — после отдельной сборки runtime).
